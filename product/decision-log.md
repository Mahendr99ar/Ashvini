# Decision log

Short entries, newest first. Each says what was decided, what else was considered, and what would make us revisit it.

## 2026-10-10: Recommend, never act

Ashvini recommends manoeuvre, monitor or dismiss. It does not plan or command burns. A person records the decision.
Considered: auto-dismissing low-risk events. Rejected because a wrong dismissal is the expensive mistake and operators carry the responsibility.
Revisit if: operators ask for bulk dismissal with an audit trail.

## 2026-10-10: Thresholds belong to the operator

Default action line is Pc 1e-4 (a common operator practice), monitor line 1e-6. Each organisation can change both, and every recommendation shows the line it used.
Revisit if: interviews show teams use miss distance instead of Pc.

## 2026-10-10: Baselines before models

Every model is compared with a plain baseline before it reaches the product. In the ESA challenge the carried-forward baseline was hard to beat, so the risk model must earn its place.

## 2026-10-10: Public data first, operator data when offered

Stage 1 runs on CelesTrak. Operators can upload CCSDS OEM ephemerides and CDMs, which replace public data for their own objects.
Revisit if: a commercial data partner offers a free research tier.
